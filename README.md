## Problems Solved

### 1. Diagonal Difference

**Topic:** 2D Arrays / Matrices

**Approach:**

* Read the square matrix.
* Calculate the sum of the primary diagonal.
* Calculate the sum of the secondary diagonal.
* Find the absolute difference between the two sums.

**Time Complexity:** O(N²)
**Space Complexity:** O(1)

**Solution:** `01-Diagonal-Difference/solution.cpp`

**Evidence:** `01-Diagonal-Difference.png`

---

### 2. Dynamic Array

**Topic:** Data Structures / Vectors

**Approach:**

* Create a collection of dynamic sequences.
* Calculate the sequence index using `(x ^ lastAnswer) % n`.
* Type 1 queries append a value to the selected sequence.
* Type 2 queries retrieve the required value and update `lastAnswer`.

**Time Complexity:** O(N + Q)
**Space Complexity:** O(N)

**Solution:** `02-Dynamic-Array/solution.cpp`

**Evidence:** `02-Dynamic-Array.png`

---

### 3. Time Conversion

**Topic:** Strings / Logic

**Approach:**

* Read the time in 12-hour format.
* Extract the hour and AM/PM period.
* Convert the hour according to the AM/PM condition.
* Display the result in 24-hour format.

**Time Complexity:** O(1)
**Space Complexity:** O(1)

**Solution:** `03-Time-Conversion/solution.cpp`

**Evidence:** `03-Time-Conversion.png`

---

### 4. Compare the Triplets

**Topic:** Basic Implementation

**Approach:**

* Compare Alice's and Bob's scores for each of the three categories.
* Increase Alice's score when her value is greater.
* Increase Bob's score when his value is greater.
* Display both scores.

**Time Complexity:** O(1)
**Space Complexity:** O(1)

**Solution:** `04-Compare-the-Triplets/solution.cpp`

**Evidence:** `04-Compare-the-Triplets.png`

---

### 5. Sparse Arrays

**Topic:** Strings / Hash Maps

**Approach:**

* Store the frequency of every input string using an `unordered_map`.
* For each query string, directly retrieve its frequency.
* If a string does not exist, its frequency is treated as zero.

**Time Complexity:** O(N + Q) average
**Space Complexity:** O(N)

**Solution:** `05-Sparse-Arrays/solution.cpp`

**Evidence:** `05-Sparse-Arrays.png`
